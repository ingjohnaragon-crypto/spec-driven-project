## Historia de usuario
Como cliente joven, quiero una cuenta de ahorro con límites de retiro diarios y una tasa de interés bonificada, para administrar mi dinero con seguridad y obtener mejores rendimientos.

## Contexto
La cuenta ayudará a los clientes jóvenes a controlar sus retiros y fomentar el ahorro. El contrato aplicará un límite diario configurable y una tasa de interés superior cuando se cumplan las condiciones de bonificación.

## Criterios de aceptación
- [ ] El contrato permite configurar un límite máximo de retiros diarios por cuenta.
- [ ] Los retiros que superen el límite diario son rechazados con un mensaje claro.
- [ ] Los retiros válidos actualizan correctamente el acumulado diario.
- [ ] El acumulado de retiros se reinicia al comenzar un nuevo día calendario.
- [ ] El contrato aplica la tasa de interés bonificada cuando se cumplen las condiciones configuradas.
- [ ] El contrato aplica la tasa de interés estándar cuando no se cumplen las condiciones de bonificación.
- [ ] Las tasas, el límite diario y las condiciones de elegibilidad son configurables.
- [ ] os-vault-test pasa (todos los tests en verde)
- [ ] os-vault-test --coverage pasa (>= 90%)
- [ ] El contrato respeta las restricciones del sandbox Python de Vault
